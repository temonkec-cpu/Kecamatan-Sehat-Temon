# SWASTI-Temon — Portal Bukti Dukung Kecamatan Sehat Kapanewon Temon

Web aplikasi terpadu untuk pengunggahan, pemantauan, dan verifikasi berkas bukti dukung 7 Tatanan Kabupaten/Kota Sehat (KKS) di wilayah Kapanewon Temon, Kulon Progo.

## Fitur Utama

- **Dashboard Real-time:** Pantau persentase keterpenuhan dokumen indikator secara langsung di Hero Section.
- **7 Tatanan Terintegrasi:** Data indikator disesuaikan dengan standar Kemenkes & Kemendagri untuk verifikasi Swasti Saba.
- **Multi-Role Simulation:**
  - **Superadmin:** Verifikasi dokumen, memberikan catatan revisi, dan pantau capaian seluruh tatanan.
  - **Tatanan/Puskesmas:** Unggah bukti dukung per indikator, pantau status verifikasi, dan tindak lanjut revisi.
- **UI/UX Modern (Pure NZ Style):** Desain bersih dengan skema warna Deep Forest Green, Gold Accent, dan Warm Cream.

## Teknologi

- **Frontend:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Build Tool:** Vite

## Struktur Data Tatanan

1. Kehidupan Masyarakat Sehat Mandiri
2. Permukiman & Fasilitas Umum Sehat
3. Satuan Pendidikan Sehat
4. Pasar Sehat & Fasilitas Perdagangan
5. Pariwisata Sehat
6. Perhubungan Sehat & Kawasan Bandara
7. Perlindungan Sosial & Penanggulangan Bencana
